# PI Reading Club

A weekly book club for eToro Popular Investors (and anyone else interested in investing and learning).

## Features

- **Book Voting** — Browse a curated list of investing and history books and vote for what to read next
- **Weekly Pick** — The most popular book each week becomes the group read
- **Community Discussion** — A dedicated page for members to share thoughts and insights
- **Email Signup** — Stay in the loop with weekly updates

## Pages

- `reading-list.html` — Main page with book list, voting, and signup
- `discussion.html` — Community discussion board

## Tech

- Three.js for 3D particle effects
- [Paper Design Shaders](https://shaders.paper.design/) for dynamic backgrounds
- LocalStorage for persisting votes and comments
